\# Education Platform — SEO Specification



\## 1. Purpose



This document defines the Search Engine Optimization strategy for the education platform.



SEO must be considered during architecture and development rather than added after the website is completed.



The platform should provide a strong technical SEO foundation while remaining compatible with:



\- HTML5

\- CSS3

\- Vanilla JavaScript

\- Supabase

\- PostgreSQL

\- Netlify



\---



\# 2. SEO Principles



The platform should follow these principles:



1\. Use semantic HTML.

2\. Create descriptive page titles.

3\. Provide meaningful meta descriptions.

4\. Use clean URLs.

5\. Use canonical URLs.

6\. Provide appropriate Open Graph metadata.

7\. Provide descriptive image alt text.

8\. Generate structured data where appropriate.

9\. Provide sitemap.xml.

10\. Provide robots.txt.

11\. Optimize page performance.

12\. Ensure mobile usability.

13\. Maintain accessible content structure.

14\. Avoid duplicate content.

15\. Avoid unnecessary JavaScript-dependent SEO content.

16\. Keep client-specific SEO information configurable.
